# 🏥 Appointment Booking System (Backend - NestJS)

A scalable backend API for an Appointment Booking System built using **NestJS**, **TypeORM**, and **JWT Authentication** with Google OAuth.

This project supports:
- Doctor slot creation (custom & recurring)
- Multi-weekday recurring slots
- Patient appointment booking
- Slot cancellation
- Role-based authentication (Doctor / Patient)
- JWT + Refresh Token authentication

---

## 🚀 Tech Stack

- Node.js
- NestJS
- TypeScript
- TypeORM
- MySQL / PostgreSQL
- JWT Authentication
- Google OAuth
- Passport.js

---

## 🔐 Authentication Flow

- Google OAuth Login
- JWT Access Token
- Refresh Token Support
- Complete Profile API
- Role-based Access (Doctor / Patient)

---

## 👨‍⚕️ Doctor Features

- Create single slot
- Create recurring slots (multi-weekday support)
- Cancel specific slot
- Cancel slots by date
- View own slots

---

## 🧑‍💻 Patient Features

- View available slots by doctor & date
- Book appointment
- Cancel appointment
- View own appointments
